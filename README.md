# TidyMinutes

Public marketing and support website for TidyMinutes, the iPhone cleaning planner by Nikolaj Brandt.

GitHub Pages: https://npb2020.github.io/tidyminutes/

- privacy.html: Privacy Policy
- terms.html: Terms of Use
- support.html: Support

Dependency-free static HTML. The mobile app is maintained separately in Replit. Planned features are labelled on the website; website changes do not modify the native app.
